# MUSTAFA — Personal Biohacking

Готовый статический сайт без внешних зависимостей. Его можно сразу публиковать на GitHub Pages: никаких `npm install`, сборки и сервера не требуется.

## Быстрый просмотр локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте новый репозиторий GitHub.
2. Загрузите в него **всё содержимое папки**.
3. Убедитесь, что основная ветка называется `main`.
4. Откройте **Settings → Pages**.
5. В `Build and deployment → Source` выберите **GitHub Actions**.
6. Workflow `.github/workflows/deploy.yml` автоматически опубликует сайт после push в `main`.

## Основные файлы

- `index.html` — структура и тексты сайта.
- `styles.css` — вся визуальная система, адаптив и анимации.
- `app.js` — интро, mobile menu, reveal-анимации, движение DNA и Telegram-форма.
- `assets/images/` — предоставленные DNA, brain и capsules visuals.
- `privacy.html` — шаблон политики конфиденциальности.
- `consent.html` — шаблон согласия на обработку данных.
- `terms.html` — информационные ограничения и дисклеймеры.

## Telegram

Все коммерческие CTA ведут на:

`https://t.me/Must1ofa1`

Форма не отправляет данные на сторонний backend. При отправке формируется текст заявки, копируется в буфер обмена и открывается Telegram. Это позволяет безопасно показать и опубликовать презентационную версию без хранения анкет на GitHub Pages.

## Нейромедиаторный тест

Ссылка на внешний тест:

`https://psytests.org/typo/bna-run.html`

На сайте тест описан только как инструмент самооценки, а не медицинская диагностика.

## Перед полноценным коммерческим запуском

Нужно заменить шаблонные юридические документы на документы с фактическими реквизитами оператора, проверить статус конкретных товаров и допустимые рекламные формулировки. Текущая архитектура сайта специально устроена так, чтобы это не требовало переделки основной страницы.

После появления финального домена добавьте canonical URL и фактические URL в `sitemap.xml`.

## GitHub Pages — лёгкая сборка

Эта версия очищена от неиспользуемых медиа и подготовлена для GitHub Pages.
Загружайте **содержимое папки `mustafa-biohacking-site`**, а не ZIP-файл как файл репозитория.
Для публикации: Settings → Pages → Source: GitHub Actions (workflow уже находится в `.github/workflows/deploy.yml`).

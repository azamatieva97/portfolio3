Политика конфиденциальности

Шаблон для презентационной версии. Перед коммерческим запуском реквизиты оператора и фактические процессы обработки данных необходимо заполнить и проверить.

1. Общие положения

Сайт может обрабатывать данные, которые пользователь добровольно передаёт для связи: имя, возраст, Telegram и текст запроса.

2. Цель

Данные используются только для ответа на обращение и коммуникации по инициативе пользователя.

3. Минимизация данных

Не отправляйте через форму медицинские документы, результаты анализов, паспортные данные и другую информацию, которая не нужна для первичного обращения.

4. Передача

При нажатии кнопки заявка не отправляется на сервер сайта: текст обращения копируется на устройство пользователя, после чего открывается Telegram @Must1ofa1.

5. Контакт

По вопросам обработки данных: Telegram @Must1ofa1.
